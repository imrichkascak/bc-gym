# BC GYM

Prezentační web samoobslužné posilovny **BC GYM** v Bohumíně.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Vercel

## Development

```bash
npm install
npm run dev
```

Otevři [http://localhost:3000](http://localhost:3000).

## Deploy

Projekt je připravený na Vercel (`bc-gym.vercel.app`).
